Features

✔ Task List

Fetches tasks from Firestore

Displays: Title, Description, Due Date, Completion Status

✔ Add Task

Users can add a new task

Task data is saved to Firestore

✔ Edit Task

Modify existing task details:

Title

Description

Due Date

✔ Delete Task

Remove a task from the Firestore database

✔ Task Completion Status

Mark a task as Completed

Toggle to mark back to Pending
